## Segmento C — Señal vs ruido
**Tipo:** `framework` · Biblia: COPIAR → F0 lección.

Framework:
- Señal = este programa + first-party data (aprender haciendo).
- Ruido = reels, YouTube de negocios, otros mentores, shiny object.
- Anteojeras de caballo **12 semanas** (AILINK = 90 días: unificar a 90 días / 13 semanas, no dejar “12”).
- Un solo mentor hasta llegar a su nivel de ingresos.
- Protocolo de duda: primero los vídeos del programa → luego Agustín. No “otro curso”.

Frase-ancla: “La señal se fortalece con first-party data. El ruido baja cuando haces, no cuando consumes.”

Recurso ligero: checklist “anteojeras” (desuscribir newsletters, un mentor, dónde preguntar).
