# F5 | Entrega — KPIs del módulo

## KPIs del alumno (semanas 8-11, solapado con captación)

| KPI | Objetivo | Se mide en |
|---|---|---|
| Formulario de arranque enviado | El mismo día del cobro | L1-L2 / R1 |
| Llamada de arranque hecha + acuerdo firmado + criterios de aceptación pactados | ≤ 48h del cobro | L2 / R2-R3 |
| Primera prueba visible de trabajo enviada al cliente | < 24h del cobro | L1 / R4 |
| 1 toque visible al día durante el build | Todo el build | L4 / R4 |
| **Piloto entregado** (QA + formación + criterios firmados) | **≤ 7 días desde el cobro** | L5 / R5 |
| Proyecto entregado | ≤ 21 días | L5 |
| Testimonio pedido EN el pico + referido pedido | El día de la entrega | L6 / R6 |
| Entrega convertida en plantilla (ritual de 30 min) | ≤ 3 días post-entrega | L7 / R7 |

## KPIs de Agustín como operador

| KPI | Benchmark objetivo | Por qué importa |
|---|---|---|
| % primeras entregas en ≤7 días | > 70% | La promesa del modelo ("días, no meses") se juega aquí |
| % entregas con testimonio capturado | > 60% | Alimenta los [PRUEBA SOCIAL] de F3 de toda la cohorte |
| % entregas con criterios de aceptación firmados | 100% | Sin firma, los proyectos no terminan nunca (scope creep) |
| Atascos de integración reportados | Registrar por tipo | 3+ repetidos → plantilla AILINK o lección FAQ |

## Reglas transversales

- El 80% del arrepentimiento de compra ocurre en las primeras 24h (heredado): primer contacto el mismo día, prueba visible <24h.
- Infrapromesa del ~30% en todo plazo comprometido.
- Cobro del proyecto 50/50 — **BORRADOR pendiente de Agustín**.
