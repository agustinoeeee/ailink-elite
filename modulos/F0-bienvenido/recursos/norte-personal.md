| **Complejidad técnica** — hasta dónde quieres meterte | | |
| **Nivel de soporte** — qué te comprometes a atender, y con qué urgencia | | |
| **Equipo futuro** — solo, con ayuda puntual o con gente contratada | | |

**Tres ejemplos de cómo se traduce**, para que veas el mecanismo:

- *No quiero estar disponible por las noches* → mi oferta **lleva horario de atención escrito** y no incluye soporte de urgencias.
- *Quiero trabajar desde cualquier sitio* → entrega en remoto y reuniones por vídeo; descarto los nichos que exigen presencia.
- *Quiero pocos clientes* → mi precio tiene que ser más alto. No es una preferencia estética: es aritmética.
