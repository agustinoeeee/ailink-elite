## D5 — Paso 3: el primer fallo
Esto no es un tropiezo. Esto es EL método.

Ciclo de 4 pasos:  
HIPÓTESIS → PRUEBA → DATO → AJUSTE

Letra pequeña: *El gesto exacto: copiar el error tal cual y pegárselo con una frase — "Al cancelar una cita pasa esto: [error pegado]. Arréglalo".*

Pie: *Lo que NO se hace: pelearte con el error, intentar descifrarlo tú, o aprovechar el arreglo para colar tres cambios más.*

> PANTALLA REAL — el fallo provocado a propósito y arreglado pegándole el error a Claude Code.
