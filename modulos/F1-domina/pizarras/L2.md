# L2 — Pizarra de explicación (Inventario de ventajas)

16:9 · 6 diapos · entregable detrás: inventario-ventajas (A4) + catalogo-oportunidades (A4). D4 y D5 son los mismos bloques del worksheet: reutiliza la composición para que el alumno reconozca la pieza.

## D1 — Título
El nicho no se elige por lo que está de moda.  
**Se elige donde tienes ventaja.**

## D2 — Herramienta vs habilidad
Dos bloques enfrentados:

**HERRAMIENTA**  
Algo que sabes usar

**HABILIDAD**  
Algo que sabes conseguir

Pie: *Claude Code lo tendrás en dos semanas, igual que otros mil. Saber por dónde pierde pacientes una clínica, no.*

> PANTALLA REAL — el worksheet inventario-ventajas abierto, recorriendo las columnas de la tabla de hechos

## D3 — Etiqueta débil → ventaja comercial
Tabla de dos columnas y cuatro filas:

| Etiqueta débil | Ventaja comercial |
| «Trabajé en administración» | Sé dónde aparecen los duplicados y los pendientes |
| «Fui comercial» | Sé cómo se pierde un lead y qué seguimiento se deja de hacer |
| «Trabajé en una clínica» | Conozco citas, confirmaciones, no-shows y facturación |
| «No tengo experiencia técnica» | Aporto el proceso y construyo con Claude Code |

Pie: *Nadie te contrata por una etiqueta.*

## D4 — Tus seis cajones
Rejilla de 6 celdas, dos filas de tres:

FUNCIONALES · SECTOR · TÉCNICAS  
ACCESO · PRUEBA · ENERGÍA

Pie: *Acceso = a quién puedes llamar mañana sin presentarte.*

## D5 — La matriz
Tabla con los 6 factores, cada uno con su pregunta y una columna «1-5» vacía:

1. **Dominio** — ¿sé cómo funciona de verdad?
2. **Acceso** — ¿puedo hablar con quien decide sin empezar de cero?
3. **Urgencia** — ¿les cuesta dinero, tiempo o reputación?
4. **Prueba** — ¿tengo algo que enseñar, o puedo construirlo rápido?
5. **Automatizable** — ¿hay volumen, reglas y datos?
6. **Energía** — ¿me veo con esta gente 90 días?

Pie: *Salida: entre 1 y 3 candidatos. Ni uno más.*

## D6 — Cómo se lee
Tres líneas, cada una con su veredicto destacado:

Mucho dominio + cero acceso → **es un hobby**  
Mucho acceso + cero urgencia → **una lista que no compra**  
Todo cincos + cero energía → **aguantas tres semanas**

Pie: *Busca el patrón, no la puntuación alta.*
