# Plantilla AILINK — Informes automáticos (despachos de abogados)

> **Kit de brief.** A diferencia de la insignia (`../recuperacion-citas-dental/`), aquí la demo NO viene construida: la construyes TÚ con Claude Code a partir del brief — esa es exactamente la habilidad de F2. La insignia es tu referencia estructural: ábrela, pruébala y cálcale el nivel antes de empezar.

## Qué contiene

| Archivo | Qué es |
|---|---|
| `BRIEF.md` | El brief COMPLETO relleno para el nicho típico (despacho de abogados) — tu primera instrucción a Claude Code, listo para entregar entero |
| `CLAUDE.md` | Las instrucciones de proyecto para Claude Code: reglas y comportamientos innegociables de esta demo |
| `README.md` | Este archivo |

## Qué construirás

El panel de datos de un despacho inventado (**Arrieta & Soler Abogados**): asuntos, horas, plazos y facturación ilustrativa del mes. El socio pulsa un botón — "Generar informe del mes" — y aparece delante de él el informe visual que antes le costaba horas montar a mano: cifras clave con comparativa, gráficas limpias y un resumen redactado en lenguaje claro con avisos de plazos. Todo en un solo archivo, sin dependencias.

## Cómo se usa (alumno)

1. **Lee el `BRIEF.md` entero** antes de escribir nada: es el ejemplo canónico del formato de F2-R2, ya relleno para este nicho.
2. **Abre la insignia** (`../recuperacion-citas-dental/index.html`) y reproduce su flujo completo: ese es el nivel de acabado al que apuntas.
3. **Copia esta carpeta** a tu espacio de trabajo con el nombre de TU proyecto y ábrela con Claude Code.
4. **Primera instrucción**: el brief entero, en lenguaje natural ("construye esta demo web siguiendo este brief: …").
5. **Itera con las 3 reglas de dirección** del final del brief: una petición = un cambio, probar entre pasos, los errores se pegan.
6. **Despliega** (F2-L2) y tendrás tu URL compartible.
7. **No la enseñes a nadie** sin pasar la checklist pre-demo de F2-L6.

## Qué NO es

- No es el piloto real: el texto del informe está guionizado para los datos de ejemplo (sin APIs de IA — decisión del programa; la redacción real con IA y la conexión a los datos del cliente llegan en F5, con el piloto pagado).
- No guarda datos: todo vive en la página y se reinicia con el botón (a propósito: cada llamada de venta empieza limpia).

## La regla que hace ganar esta demo

Todas las cifras del informe deben cuadrar con la tabla de datos del panel. Es lo primero que un abogado o un gestor comprueba — y cuando cuadra delante de él, la demo se vende sola.

## Adaptación rápida a otros nichos (mismo esqueleto)

Gestorías y asesorías (el nicho hermano: trámites presentados, horas por empleado, informe mensual por cliente), clínicas (citas, no-shows, facturación por tratamiento), talleres (reparaciones y ticket medio), academias (matrículas y cuotas): cambia asuntos→tu unidad de trabajo, materias→tus categorías, los datos y el texto guionizado del resumen. La estructura panel → botón → informe es idéntica.
