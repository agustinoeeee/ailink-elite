# Plantillas AILINK — los "repos base" del programa

> Los "repos base" del programa: una plantilla por solución del catálogo. El alumno las clona, las personaliza con Claude Code y despliega su demo en horas, no en días. Referenciadas en F2-L5 (`[PLANTILLAS AILINK]`), F5-L3 y F6.

**Por diseño, solo la insignia trae la demo construida.** Los otros 7 son kits de brief completos: el alumno construye SU demo con Claude Code a partir del brief (esa ES la habilidad de F2) usando la insignia como referencia estructural. Cualquiera de los 7 puede convertirse en demo funcionando bajo pedido (mismo proceso que la insignia).

## Anatomía de cada plantilla

- `README.md` — qué es, cómo usarla, qué NO es
- `CLAUDE.md` — instrucciones de proyecto para Claude Code (reglas, qué no tocar, los comportamientos innegociables)
- `BRIEF.md` — el brief COMPLETO relleno para su nicho típico (formato de F2-R2), listo para dárselo a Claude Code
- `index.html` — solo en la insignia: la demo funcionando

## Reglas de la casa (aplican a las 8)

1. **Demo = conversación/flujo GUIADO**, sin texto libre ni APIs de IA (decisión del programa: el cerebro real llega en F5 con el piloto pagado).
2. **Un solo archivo desplegable** cuando sea posible; sin dependencias externas.
3. **Datos ficticios verosímiles** en español de España; cifras "ilustrativas".
4. **Botón "reiniciar demo" siempre** — cada llamada de venta empieza limpia.
5. **Móvil primero.** Nada se enseña sin la checklist pre-demo de F2-L6.
